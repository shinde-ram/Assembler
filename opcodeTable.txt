--> Encoding-Requirement Legend

Field	            Meaning
------              --------
ModR/M = Yes	    ModR/M byte is required
SIB = Optional	    SIB may be required depending on memory addressing
Disp = Optional	    Displacement depends on addressing mode
Imm = 8/16/32	    Immediate of specified size
/r	                ModR/M REG field encodes a register operand
/0–/7	            ModR/M REG field contains opcode extension
+rd	                Register number is encoded into opcode
REL8/REL32	        Relative offset used by control-flow instruction
